Java Date & Time API — 10 Problem Statements :

1.	Employee Joining Date Analysis
Create a program that stores an employee's joining date using LocalDate and 
calculates the employee's total years, months, and days of service using Period.

2.	Student Exam Schedule
Given an examination date, use LocalDate to display the day of the week, calculate the number of 
days remaining until the examination, and determine whether the exam falls in a leap year.

3.	Meeting Time Zone Converter
Create a program that accepts a meeting date and time in Asia/Kolkata and converts it to 
America/New_York and Europe/London using ZonedDateTime.

4.	Employee Age Calculator
Accept an employee's date of birth and calculate their exact age in years, months, and 
days using LocalDate and Period.

5.	Training Session Duration
Given the start and end time of a training session, use LocalTime and 
Duration to calculate the total duration in hours, minutes, and seconds.

6.	Date Formatting and Parsing
Accept a date in the format dd/MM/yyyy, convert it into a LocalDate using DateTimeFormatter, 
and display it in the formats dd-MM-yyyy, MMMM dd, yyyy, and EEEE, dd MMMM yyyy.

7.	Project Deadline Calculator
Given a project start date and the number of weeks allocated to the project, 
calculate the project deadline using LocalDate and display the remaining days 
between the current date and the deadline.

8.	Last Friday of the Month
Given a month and year, use TemporalAdjusters and 
DayOfWeek to find and display the last Friday of that month.

9.	Online Transaction Timestamp
Create a program that records the current transaction time using Instant, converts it to 
ZonedDateTime for Asia/Kolkata, and displays both the UTC timestamp and Indian local time.

10.	Subscription Expiry Checker
Given a subscription start date and subscription duration in months, calculate the expiry date 
using LocalDate and Period. Determine whether the subscription is currently active or expired.
