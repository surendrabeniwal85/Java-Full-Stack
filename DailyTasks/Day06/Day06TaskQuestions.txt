Exception Handling

S. No.	Topic	Problem Statement
1	Basic try-catch	Write a Java program to handle an arithmetic exception using try-catch. 
    Perform division of two numbers and handle the exception that occurs when the denominator is zero.
2	Multiple catch	Write a Java program to demonstrate multiple catch blocks.
    Perform arithmetic and array operations and handle ArithmeticException and ArrayIndexOutOfBoundsException separately.
3	finally	Write a Java program to demonstrate the use of the finally block.
    Perform an arithmetic operation inside a try block and display a message from the finally block whether an exception occurs or not.
4	try-catch-finally	Write a Java program to implement complete exception handling using try, catch, and finally.
    Demonstrate exception handling and execute a cleanup statement using the finally block.
5	Array Exception	Write a Java program to handle ArrayIndexOutOfBoundsException. 
    Create an integer array, accept an index from the user, and display the corresponding element. Handle the situation when the entered index is invalid.
6	String/Null Exception	Write a Java program to handle NullPointerException. 
    Create a String object that may contain a null value and safely perform an operation on it using exception handling.
7	Number Format	Write a Java program to handle NumberFormatException. 
    Accept a number as a String, convert it into an integer, and handle the exception if the user enters a non-numeric value.
8	File Handling	Write a Java program to read a file using FileInputStream and handle FileNotFoundException.
    Display an appropriate message when the specified file does not exist.
9	throw	Write a Java program to demonstrate the throw keyword. 
    Check the age of a person and explicitly throw an exception if the person is below 18 years of age.
10	throw + catch	Write a Java program to validate a student's marks using the throw keyword. 
    Explicitly throw an exception if the entered marks are less than 0 or greater than 100 and handle the exception using catch.
11	throws	Write a Java program to demonstrate the throws keyword. 
    Create a method that performs file reading and declare FileNotFoundException using throws. Handle the exception in the calling method.
12	Multiple throws	Write a Java program to demonstrate a method declaring multiple exceptions using throws. 
    Create a method that performs arithmetic and array operations and declare the possible exceptions in the method signature.
13	throw vs throws	Write a Java program demonstrating the difference between throw and throws.
    Use throw to explicitly generate an exception and throws to declare an exception that may be generated by a method.
14	Custom Exception – Age	Write a Java program to create a custom exception named InvalidAgeException. 
    Use it to validate a person's age and generate the custom exception when the age is below 18 years.
15	Custom Exception – Marks	Write a Java program to create a custom exception named InvalidMarksException. 
    Accept marks from the user and throw the custom exception when the marks are outside the valid range of 0 to 100.
16	Custom Exception – Bank	Write a Java program to create a custom exception named InsufficientBalanceException for a banking application. 
    Perform a withdrawal operation and throw the custom exception when the requested amount is greater than the available balance.
17	Checked Exception	Write a Java program to demonstrate a checked exception using file handling. 
    Attempt to open and read a file using FileInputStream and handle FileNotFoundException using try-catch or throws.
18	Unchecked Exception	Write a Java program to demonstrate unchecked exceptions. 
    Perform operations that may generate ArithmeticException, ArrayIndexOutOfBoundsException, or NullPointerException and handle the exceptions appropriately.
19	Checked vs Unchecked	Write a Java program to demonstrate the difference between checked and unchecked exceptions.
    Use a file operation to demonstrate a checked exception and an arithmetic or array operation to demonstrate an unchecked exception.
20	Complete Exception Handling	Write a Java program to develop a simple banking application demonstrating complete exception handling. 
    Use try-catch-finally, throw, throws, and a custom InsufficientBalanceException to validate deposits, withdrawals, and account operations.
